# ATLAS — Personal AI Manager

> Plan. Execute. Follow up.

An agentic personal-management system: tell it what's on your mind in plain
language, and it extracts your goals, tasks, commitments, and events, breaks big
goals into steps, schedules the work into your free time, and gives you a daily
brief that proactively surfaces commitments you've let slip.

This is the **Manager Loop** core — the spine the rest of ATLAS layers onto.

## The loop

```
natural language  ->  extract (goal | task | commitment | event)
                  ->  decompose goals into subtasks
                  ->  schedule tasks into free work blocks (earliest deadline first)
                  ->  daily brief + follow-up on overdue commitments
```

## Run it

```bash
cd backend
python -m venv .venv && .venv\Scripts\activate      # Windows
pip install -r requirements.txt
set ANTHROPIC_API_KEY=sk-ant-...                     # your key
uvicorn main:app --reload
```

Open the app in **Chrome or Edge** and **talk** to ATLAS — tap the mic and speak
(hands-free mode keeps the conversation going), or type:

> Schedule a 1-hour gym session tomorrow at 6pm, and remind me to submit my AI
> project Friday. Also check my email for anything urgent.

ATLAS listens, talks back (speech), and takes real actions — decomposes the
goal, schedules work into free time, creates the calendar event, scans Gmail for
action items, and the daily brief flags the HR call if it goes overdue.

Voice uses the browser's built-in Web Speech API (no extra key). Gmail: ATLAS
reads your inbox and can prepare **drafts** for your review — it never sends mail.

## Connect Google Calendar (optional but recommended)

Without this, ATLAS runs in local-only mode (badge shows "calendar: not
connected"). To let it read/write real events:

1. **Google Cloud Console** → create a project (or reuse one).
2. **APIs & Services → Library** → enable **Google Calendar API** *and* **Gmail API**.
3. **APIs & Services → OAuth consent screen** → User type **External** →
   fill app name + your email → **Add users** → add your own Gmail as a test user.
4. **APIs & Services → Credentials → Create credentials → OAuth client ID** →
   application type **Desktop app** → Create → **Download JSON**.
5. Save that file as `backend/credentials.json`.
6. Authorize once:
   ```bash
   cd backend && python authorize.py
   ```
   A browser opens — sign in, click Allow. This writes `backend/token.json`.

Restart the server; the badge turns green and scheduling syncs to your calendar.
Set your timezone with `ATLAS_TZ` (default `Asia/Kolkata`).

## Message ATLAS on Telegram (optional)

Talk to your assistant from your phone — no public URL or hosting needed
(long-polling). It shares this database, so anything you do on Telegram appears
on the web dashboard and vice versa.

1. In Telegram, open **@BotFather** → `/newbot` → follow the prompts → copy the token.
2. Add it to `ATLAS/.env`:  `TELEGRAM_BOT_TOKEN=123456789:ABC...`
3. Run the bot alongside the server:
   ```bash
   cd backend && python telegram_bot.py
   ```
4. Open your bot in Telegram and say hi.

Calendar/email actions arrive as **Approve / Cancel** buttons — same permission
tiers as the web app.

## Install on your phone (PWA)

ATLAS is an installable Progressive Web App — full-screen, home-screen icon,
cached shell for instant loads.

- **Android/Chrome:** open the app → tap **⬇ Install app** in the top bar (or
  the browser's "Install / Add to Home screen").
- **iOS/Safari:** Share → **Add to Home Screen**.

To reach it from your phone, run the server on your PC and open
`http://<your-PC-LAN-IP>:8077` on the phone (same Wi-Fi), e.g. start it with
`uvicorn main:app --host 0.0.0.0 --port 8077`. Icons are generated by
`python generate_icons.py` (needs Pillow, build-time only).

## API

| Method | Path | Purpose |
|--------|------|---------|
| POST | `/api/chat`    | `{messages}` -> live agent loop (tools: capture, calendar, brief) |
| POST | `/api/capture` | `{text}` -> extract + store + schedule |
| GET  | `/api/brief`   | daily brief (counts, schedule, attention, pending) |
| GET  | `/api/items`   | list items (`?status=open`) |
| PATCH| `/api/items/{id}` | `{status}` — mark done/dropped |
| DELETE | `/api/items/{id}` | delete item + subtasks |
| POST | `/api/replan`  | re-run the scheduler |
| POST | `/api/execute` | `{tool,input}` — run a proposed action after user approval |
| GET/PUT | `/api/settings` | permission tiers per tool (`auto` / `ask`) |

## Architecture (the 5 brains)

| Brain | Where it lives now |
|-------|--------------------|
| **Memory** | SQLite `items` table (goals, tasks, commitments, events) |
| **Planner** | `schedule_unplanned()` — greedy earliest-deadline scheduler |
| **Manager** | `build_brief()` — prioritizes + surfaces what needs you |
| **Verifier** | commitment follow-up in the brief + proactive reminder loop (browser notifications + spoken nudges every 60s) |
| **Guardrails** | permission tiers — outward actions (calendar/email) are proposed as Approve/Cancel cards unless set to `auto` in ⚙ Permissions |
| **Channels** | web (voice + dashboard) and Telegram (`telegram_bot.py`) share one agent (`run_agent`) and one database |
| **Purchasing** | research → `propose_purchase` → Approve opens the store for **you** to pay. ATLAS never enters payment details or checks out (always-ask, cannot be automated) |
| **Agent** | `/api/chat` tool loop — captures items, creates real Google Calendar events, scans Gmail + drafts replies, and researches the live web (search + read + recommend) |

## Deploy to Render (public HTTPS URL)

A public HTTPS host is what makes the PWA installable and the microphone work on
phones (Web Speech needs a secure context). This repo ships a `render.yaml`
blueprint.

1. **Push to GitHub** (from the `ATLAS/` folder):
   ```bash
   git init && git add -A && git commit -m "ATLAS"
   git branch -M main
   git remote add origin https://github.com/<you>/atlas.git
   git push -u origin main
   ```
2. **Render** → New → **Blueprint** → pick the repo → Apply. It reads
   `render.yaml` (Python web service, `rootDir: backend`, start command
   `uvicorn main:app --host 0.0.0.0 --port $PORT`).
3. In the service's **Environment** tab, set the secrets (`sync: false` keys):
   - `ANTHROPIC_API_KEY` — required.
   - `GOOGLE_CREDENTIALS_JSON` / `GOOGLE_TOKEN_JSON` — optional. Run
     `python authorize.py` locally, then paste the **contents** of
     `credentials.json` and `token.json`. On boot the app writes them to disk,
     so Calendar/Gmail work with no interactive login on the server.
   - `TELEGRAM_BOT_TOKEN` — optional; with `RUN_TELEGRAM_IN_WEB=1` the bot runs
     inside the same service (no extra worker).
4. Open the Render URL. Install it on your phone from the browser menu.

**Data durability:** the free tier's disk is ephemeral — tasks reset when the
instance restarts/spins down. For persistence, attach a paid **Render Disk** and
set `ATLAS_DB=/var/data/atlas.db`, or migrate to Supabase/Postgres (swap the
`db()` helper + `SCHEMA`; the rest of the code is storage-agnostic).

**Note:** free web services sleep after inactivity; the first request (and the
Telegram bot) wake on the next hit. A scheduled ping to `/api/brief` keeps it
warm and can push your morning brief.
